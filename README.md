# Weather Diary

## Автор проекта

**Автор:** Джамиев Надир
**Дата:** 04.05.2026

## Описание

Приложение «Weather Diary» — это графическое приложение (GUI) для ведения дневника погоды. Оно позволяет:

* добавлять записи о погоде с указанием даты, температуры, описания и наличия осадков;
* просматривать все записи в виде таблицы;
* фильтровать записи по дате и температуре;
* сохранять данные в формате JSON и загружать их при следующем запуске.

## Функциональность

* **Добавление записей:** ввод даты (в формате YYYY‑MM‑DD), температуры (в °C), описания погоды и отметки о наличии осадков.
* **Валидация данных:** проверка корректности формата даты, числового значения температуры и непустоты описания.
* **Просмотр записей:** отображение всех записей в виде удобной таблицы с колонками «Дата», «Температура», «Описание» и «Осадки».
* **Фильтрация:** возможность фильтровать записи:
    * по конкретной дате;
    * по температуре (показать записи с температурой выше указанного значения).
* **Сохранение и загрузка:** автоматическое сохранение всех записей в файл `weather_data.json` и загрузка их при запуске приложения.
* **Сброс фильтров:** кнопка для сброса всех фильтров и отображения полного списка записей.

## Технологии

* **Python 3.x** — основной язык программирования.
* **Tkinter** — библиотека для создания графического интерфейса (GUI).
* **JSON** — формат для сохранения и загрузки данных.
* **Git** — система контроля версий.

## Примеры использования

* Добавление корректной записи
1. Введите дату в формате YYYY-MM-DD, например, 2024-05-15.
2. Введите температуру, например, 22.
3. Введите описание, например, Солнечно, ясно.
4. Отметьте чекбокс «Осадки», если нужно.
5. Нажмите кнопку «Добавить запись».

Ожидаемый результат: новая запись появляется в таблице внизу окна. Данные сохраняются в файле weather_data.json.
